# Data Policy

## Customer-Level Derived Dataset

The local project contains Customer_Segmentation.csv.

This customer-level derived dataset is NOT automatically included in the public GitHub package.

Classification: REVIEW_BEFORE_PUBLICATION

Default policy: EXCLUDE_FROM_PUBLIC_REPOSITORY_UNLESS_EXPLICITLY_APPROVED

The local file remains outside the GitHub package for controlled verification work.

## Public Reproduction

A public reproduction should use an appropriately sourced and permitted version of the underlying Online Retail transaction data.

Before publication, review licensing, provenance, privacy considerations, and redistribution rights.
